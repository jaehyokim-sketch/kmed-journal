# 경혈학실습 & 경혈학임상술기실습 일지

**탐혈·자침·초음파영상 통합 실습 기록부 (Group Practice Journal)**  
원광대학교 한의과대학 경혈학교실 & 침구의학교실

---

## 개요

`group-journal.html` 은 단일 HTML 파일로 동작하는 조별 실습 일지 웹앱입니다.  
외부 서버·DB 없이 브라우저만으로 완전히 동작하며, JSON 형식으로 데이터를 저장·복원합니다.  
여러 학습자가 개별 저장한 파일을 **파일 통합** 기능으로 하나의 조 단위 일지로 합칠 수 있습니다.

---

## 주요 기능

### 1. 기본 메타 정보 입력
- 실습 날짜, 분반(01/02분반), 조(1–10조), 실습 주제, 지도 교수
- 참여자 명단: 시술자 4명, 피시술자 2명, 관찰자 1명

### 2. 섹션 구성

| # | 섹션 | 주요 내용 |
|---|------|-----------|
| 1 | 관찰자 기록 | 위생관리 체크리스트(14점), 안전관리 체크리스트(20점) |
| 2 | 피시술자 정보 | 생체징후(체온·혈압·**맥박수**·혈당), 시술 전후 상태, 동의서 확인 — 피시술자 추가 가능 |
| 3 | 탐혈/시술 및 초음파영상 실습 기록 | 경맥·경혈 선택, 사전학습, 탐혈 과정, 자침 기록(방향·각도·깊이), 자침 사진 첨부, 초음파 영상(T/L 다중 슬롯) — 경혈별 카드 추가 가능 |
| 4 | 학습에 대한 성찰 | 학습자별 이름 + 성찰 내용, 행 자동 추가 |
| 5 | 관찰자 모의 OSCE 채점 | 경혈 위치·깊이·체위·태도·지혈 5개 항목(각 2점), OSCE 사진 첨부 |

### 3. 데이터 관리

| 기능 | 설명 |
|------|------|
| **JSON 저장** | 모든 입력값·이미지를 JSON 파일로 저장 |
| **JSON 불러오기** | 저장된 JSON 파일을 불러와 전체 상태 복원 |
| **PDF 저장** | 브라우저 인쇄 대화상자 호출, 파일명 자동 설정 |
| **파일 통합** | 개별 학습자 JSON 파일 2–6개를 하나의 조 일지로 통합 |
| **자동 저장** | 브라우저 localStorage 기반 5분 자동 임시저장, 탭 재방문 시 복원 제안 |

---

## 파일명 규칙

### JSON 저장
```
날짜_분반_조_실습주제_HH-MM-SS.json
예) 20260920_01_10조_족양명위경_14-30-00.json
```

### PDF 저장
```
날짜_분반_조_실습주제.pdf
예) 20260920_01_10조_족양명위경.pdf
```

---

## 파일 통합 사용법

> 개별 학습자가 각자 다른 경혈 데이터를 입력·저장한 JSON 파일을 하나로 합칩니다.

1. 우측 상단 **파일 통합** 버튼 클릭
2. 팝업에서 JSON 파일을 드래그하거나 **파일 선택** 버튼으로 2–6개 파일 추가
3. **기준 파일** 선택 (cover·체크리스트·OSCE 기본값이 담긴 파일)
4. **통합 실행** 클릭

통합 결과:

| 항목 | 통합 방식 |
|------|----------|
| 표지·체크리스트·OSCE | 기준 파일 데이터 사용 |
| 탐혈/시술 기록 (섹션 3) | 모든 파일의 경혈 카드를 파일 순서대로 병합 |
| 자침 사진·초음파 이미지 | 각 파일 카드 번호 재매핑으로 충돌 없이 전체 보존 |
| 학습에 대한 성찰 (섹션 4) | 모든 파일의 성찰 항목 수집·중복 제거 후 병합 |

## 기술 사양

| 항목 | 내용 |
|------|------|
| 파일 형식 | 단일 HTML 파일 (인라인 CSS + JS) |
| 외부 의존성 | Google Fonts (`Noto Sans KR`, `Noto Serif KR`) — 인터넷 연결 필요 |
| 브라우저 호환 | Chrome / Edge / Safari 최신 버전 권장 |
| 상태 저장 구조 | `vals[]` (positional) + `entries[]` + `reflectEntries[]` + `imgs{}` (base64 Data URL) |
| 이미지 저장 | base64 Data URL — JSON 내 포함, 외부 서버 불필요 |
| 자동 저장 | `localStorage` — 브라우저·기기별 독립 저장 |

---

## 주의 사항

- 이미지 첨부가 많을수록 JSON 파일 크기가 커집니다. 대용량 이미지는 저장 전 압축을 권장합니다.
- `localStorage` 자동 저장은 브라우저 및 기기별로 독립 저장됩니다. 반드시 JSON 파일로 명시적 저장하십시오.
- PDF 저장 시 브라우저 인쇄 대화상자에서 **대상: PDF로 저장** 또는 **Microsoft Print to PDF** 를 선택하십시오.
- 파일 통합 후에는 반드시 내용을 확인하고 새 JSON 파일로 저장하십시오.
