# 경혈학실습 & 경혈학임상술기실습 일지

**원광대학교 한의과대학 경혈학교실 & 침구의학교실**
탐혈·자침·초음파영상 통합 실습 기록부 (Group Practice Journal)

🌐 온라인 접속: [https://damjjaeng.github.io/kmed-journal/](https://damjjaeng.github.io/kmed-journal/)

---

## 개요

이 실습일지는 경혈학실습 및 경혈학임상술기실습 수업에서 조별로 사용하는 **웹 기반 실습 기록 도구**입니다. 별도의 설치 없이 브라우저에서 바로 실행되며, 작성한 데이터를 파일로 저장하고 나중에 다시 불러오거나 PDF로 제출할 수 있습니다.

---

## 실습일지 구성

| 섹션 | 내용 |
|------|------|
| **기본 정보** | 실습 날짜, 분반, 조, 실습 주제, 지도 교수 |
| **참여자 명단** | 시술자 3명 + 관찰자 1명 이름 기재 |
| **섹션 1** | 위생·감염 예방 체크리스트 (14점 만점) |
| **섹션 2** | 안전·자침 전 확인 체크리스트 (20점 만점) |
| **섹션 3** | 경혈별 실습 기록 (최대 6경혈) |
| **섹션 4** | 시술자별 수행 관찰 및 피드백 (피시술자 작성) |
| **섹션 5** | 관찰자 모의 OSCE 채점 |

---

## 작성 방법

### 1단계 — 기본 정보 입력
상단 표지에서 실습 날짜, 분반(01분반/02분반), 조(1조~10조), 실습 주제, 지도 교수명을 입력합니다. 참여자 명단에 시술자(1~3번) 및 관찰자 이름을 기재합니다.

### 2단계 — 체크리스트 작성 (섹션 1·2)
각 항목을 **2점(완전 수행) / 1점(부분 수행) / 0점(미수행)** 버튼으로 채점합니다. 합산 점수가 자동으로 표시됩니다.
- 섹션 1: 위생·감염 예방 7개 항목 → 14점 만점
- 섹션 2: 안전·자침 전 확인 10개 항목 → 20점 만점

### 3단계 — 경혈별 기록 추가 (섹션 3)
**+ 경혈 추가** 버튼을 눌러 경혈 기록 블록을 생성합니다. 최대 6개까지 추가할 수 있습니다. 각 블록에서 순서대로 작성합니다.

1. **경혈 선택**: 경락(14경락) → 경혈(361혈) 순서로 드롭다운에서 선택
2. **사전학습 정리**: 취혈 방법, 국소 해부, 임상 적응증, 주의사항 기재
3. **탐혈 과정**: 체표 랜드마크 확인, 탐혈 방법, 취혈 지점 설명, 초음파 영상 첨부
4. **자침 기록**
   - 자침 방향 및 각도: 직자·사자·횡자·자침하지 않음 중 선택 후 각도 입력
   - 자침 깊이, 침 굵기, 목표 구조물 기재
   - 득기감(침감) 및 피시술자 반응 기술
   - 자침 사진 첨부 (선택)
   - 이상반응 및 대처방법 기재

### 4단계 — 피드백 작성 (섹션 4)
피시술자가 시술자별 수행에 대한 관찰 및 피드백을 직접 작성합니다.

### 5단계 — OSCE 채점 (섹션 5)
관찰자가 각 시술자를 대상으로 모의 OSCE 항목에 따라 채점하고 종합 피드백을 기재합니다.

## 데이터 저장 및 불러오기

상단 툴바의 메뉴를 사용합니다.

### 💾 데이터 저장
현재 작성된 모든 내용(텍스트, 선택값, 이미지 포함)을 **JSON 파일**로 저장합니다. 파일명은 `경혈학실습일지_YYYY-MM-DD.json` 형식으로 자동 생성됩니다.

> ⚠️ 이미지를 많이 첨부한 경우 파일 크기가 커질 수 있습니다. 저장 전 꼭 파일 크기를 확인하세요.

### 📂 불러오기
이전에 저장한 JSON 파일을 선택하면 모든 입력 내용과 이미지가 복원됩니다. 기존 내용은 덮어쓰여지므로 주의하세요.

### 📄 PDF 저장
브라우저의 인쇄 대화상자가 열립니다. **대상/프린터**에서 **"PDF로 저장"** 또는 **"Microsoft Print to PDF"** 를 선택하여 PDF 파일로 저장합니다.

> Chrome 브라우저 권장. 배경 그래픽 옵션을 활성화하면 더 보기 좋게 출력됩니다.

### 🖨️ 인쇄
브라우저 인쇄 기능을 직접 실행합니다.

### 🗑️ 초기화
모든 입력 내용을 지우고 처음 상태로 되돌립니다. **저장되지 않은 데이터는 복구할 수 없으므로** 초기화 전 반드시 저장하세요.

---

## 자동 저장

브라우저를 실수로 닫거나 새로고침하더라도 **30초마다 자동 저장**됩니다. 다음 접속 시 이전 작업을 복원할지 묻는 메시지가 표시됩니다.

> 자동 저장은 브라우저 내부 저장공간(localStorage)을 사용합니다. 이미지가 많으면 자동 저장이 실패할 수 있으므로, 중요한 작업은 반드시 **💾 데이터 저장**을 이용하세요.

---

## 제출 방법

1. 실습 종료 후 **💾 데이터 저장**으로 JSON 파일 저장
2. **📄 PDF 저장**으로 PDF 파일 생성
3. 지도 교수 안내에 따라 PDF 또는 JSON 파일을 제출

| 구분 | 권장 환경 |
|------|----------|

| **기기** | PC 또는 태블릿 권장 (스마트폰 가능하나 입력 불편) |

## 자주 묻는 질문

**Q. 저장한 JSON 파일을 다른 기기에서 불러올 수 있나요?**
네, 가능합니다. JSON 파일을 이메일 또는 USB로 이동한 뒤 다른 기기에서 실습일지를 열고 **📂 불러오기**를 사용하면 모든 내용이 복원됩니다.

**Q. 이미지도 저장되나요?**
네. 첨부한 이미지는 JSON 파일 내에 포함되어 저장됩니다. 이미지가 많을수록 파일 크기가 커집니다.

**Q. PDF에 이미지가 안 보여요.**
PDF 저장 전 브라우저 인쇄 설정에서 **"배경 그래픽"** 옵션을 활성화하세요.

**Q. 경혈을 잘못 선택했어요.**
각 경혈 블록 우측의 **✕** 버튼으로 해당 블록을 삭제하고 다시 추가하세요.

**Q. 자동 저장이 실패했다는 표시가 나타나요.**
이미지 데이터가 많아 브라우저 저장공간 한도를 초과한 것입니다. 상단 메뉴의 **💾 데이터 저장**으로 파일 저장을 즉시 진행하세요.
