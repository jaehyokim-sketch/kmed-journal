# 경혈학실습 & 경혈학임상술기실습 일지

원광대학교 한의과대학 경혈학교실 · 침구의학교실

---

## 개요

탐혈·자침·초음파영상 통합 실습을 위한 조별 실습일지입니다.  
단일 HTML 파일로 구성되어 별도 설치나 서버 없이 브라우저에서 바로 사용할 수 있습니다.

**실습일지 바로가기 →** https://damjjaeng.github.io/kmed-journal/group-journal.html

---

## 주요 기능

### 실습 기록

- **섹션 1** — 관찰자 기록 (위생·안전관리 체크리스트 및 자동 채점)
- **섹션 2** — 피시술자 정보 (생체징후: 체온·혈압·혈당)
- **섹션 3** — 탐혈/시술 및 초음파영상 실습 기록 (경혈별 아코디언 카드)
- **섹션 4** — 개인 성찰 (조원 전체)
- **섹션 5** — 관찰자 모의 OSCE 채점 결과 이미지 첨부

### 경혈 선택

- 14경맥 + 경외기혈 전체 경혈 드롭다운 제공
- **★ 표시**: 세계중의학본과교육표준(SCM0003-2009) 상용수혈 130穴 강조
- 경혈 기록은 전체 경맥 경혈 수(361穴) 한도 내 자유롭게 추가

### 데이터 저장 및 통합

| 기능  | 설명  |
| --- | --- |
| 데이터 저장 | 작성 내용을 JSON 파일로 로컬 저장 |
| 불러오기 | 저장된 JSON 파일을 불러와 이어서 작성 |
| **파일 통합** | 조원별 개별 저장 파일을 하나의 최종 일지로 자동 병합 |
| PDF 저장 | 브라우저 인쇄 기능으로 PDF 출력 |

#### 파일 통합 알고리즘

- 섹션 3 경혈 기록: **모든 파일**에서 수집 후 합산
- 섹션 4 성찰: **모든 파일**에서 비어 있지 않은 항목 수집
- 기본정보·체크리스트·섹션 5: **기준 파일**(사용자 선택) 적용
- 이미지: 모든 파일에서 통합 (기준 파일 우선)

## 사용 방법

### 개별 실습 진행

1. 실습일지 페이지를 열고 **기본정보**(날짜·분반·조·주제·지도교수)를 입력합니다.
2. 조원 이름을 입력하고 역할(시술자·피시술자·관찰자)을 확인합니다.
3. 각 섹션을 순서에 따라 작성합니다.
4. 작성 중 수시로 **[데이터 저장]** 버튼을 눌러 JSON 파일로 저장합니다.

### 조별 최종 일지 완성 (파일 통합)

1. 조원 각자가 섹션 3(자신이 시술한 경혈 기록)과 섹션 4(성찰)를 작성하고 저장합니다.
2. 조장이 **[파일 통합]** 버튼을 클릭합니다.
3. 조원 전체의 JSON 파일을 선택합니다.
4. 기준 파일(기본정보 및 섹션 1·2·5 기준)을 선택합니다.
5. **[통합 실행]**을 클릭하면 모든 경혈 기록과 성찰이 합쳐진 최종 일지가 완성됩니다.
6. 최종 일지를 저장하거나 PDF로 출력합니다.

경혈 선택 드롭다운에서 **★**이 붙은 경혈은 세계중의학본과교육표준(SCM0003-2009)에서 지정한 **상용수혈 130穴**입니다.

| 수태음폐경 | 6穴  |
| 수양명대장경 | 7穴  |
| 족양명위경 | 13穴 |
| 족태음비경 | 7穴  |
| 수소음심경 | 6穴  |
| 수태양소장경 | 4穴  |
| 족태양방광경 | 20穴 |
| 족소음신경 | 4穴  |
| 수궐음심포경 | 5穴  |
| 수소양삼초경 | 9穴  |
| 족소양담경 | 14穴 |
