# 경혈학실습 포털 · 원광대학교 한의과대학

> 원광대학교 한의과대학 경혈학교실 &amp; 침구의학교실  
> GitHub Pages: https://damjjaeng.github.io/kmed-journal/

---

## 개요

경혈학실습 및 경혈학임상술기실습에서 사용하는 두 가지 웹 기반 실습 도구입니다.  
별도 설치 없이 브라우저만으로 사용 가능하며, 모든 데이터는 JSON 파일로 저장·불러오기 할 수 있습니다.

---

## 실습 도구

### ① 피험자 동의 및 시술 사전-사후 체크리스트

**파일:** `checklist.html`  
**접속:** https://damjjaeng.github.io/kmed-journal/checklist.html

피험자(피시술자) 동의서 작성부터 시술 전·후 체크리스트까지 세 단계를 하나의 문서로 통합 관리합니다.  
탭별 입력 시각을 자동 기록하여 최종 출력본(PDF)에 타임스탬프가 표시됩니다.

#### 주요 기능

| 기능 | 설명 |
|------|------|
| 피험자 동의서 | 기본 정보, 실습 목적·범위, 시술 동의 항목 포함 |
| 시술 행위 동의 (15종) | 초음파 영상관찰, 자침(毫鍼), 온침, 화침, 뜸, 자락, 부항, 전침, 약침, 매선, 두침, 이침, 침도, 사암침 등 |
| 노출·접촉 부위 체크 | 시술 부위 명시 및 동의 |
| 사전 체크리스트 | 자침 시술 전 준비사항, 피시술자 상태 확인 |
| 사후 체크리스트 | 시술 후 이상반응 확인, 사후 관리 기록 |
| 생체징후 기록 | 혈압, 맥박, 호흡수, 체온 |
| 타임스탬프 자동 기록 | 동의서·사전·사후 탭별 입력 시각 기록 및 출력본 표시 |
| JSON 저장/불러오기 | 작성 내용 저장·복원 |
| PDF 출력 | 브라우저 인쇄 기능 활용 |

#### 섹션 구성 (피험자 동의서 탭)

1. 기본 정보 (피험자·실습 참가자 공통)
2. 실습 목적 및 범위
3. 시술 내용 및 절차
4. 이상반응 및 위험성
5. 술기 및 시술 행위 동의
6. 노출 및 접촉 부위 동의
7. 실습 전 확인사항
8. 동의 서명

### ② 경혈학실습 & 경혈학임상술기실습 일지

**파일:** `group-journal.html`  
**접속:** https://damjjaeng.github.io/kmed-journal/group-journal.html

탐혈·자침·초음파영상 기록을 통합한 조별 실습일지입니다.  
조원별 개별 저장 파일을 하나의 최종 일지로 자동 병합하는 **파일 통합(Merge)** 기능을 지원합니다.

#### 주요 기능

| 기능 | 설명 |
|------|------|
| 위생·안전 체크리스트 | 관찰자 위생 및 안전 준수 항목 |
| 피시술자 생체징후 | 혈압, 맥박, 호흡수, 체온 |
| 경혈 기록 (361穴) | 탐혈·자침 결과, 득기 여부, 자침 깊이·각도 |
| 초음파영상 첨부 | 횡단면·종단면 각 5장, 탐촉자 및 Depth/Gain 개별 입력 |
| 식별층 확인 | 피하지방, 근육, 신경, 혈관, 내부 장기 여부 |
| 개인 성찰 | 실습 후 학습 성찰 기록 |
| OSCE 채점 | 채점 결과 기록 |
| JSON 저장/불러오기 | 조원별 개별 파일 저장·복원 |
| 파일 통합(Merge) | 조원별 JSON 파일을 하나의 최종 일지로 자동 병합 |
| PDF/인쇄 출력 | 브라우저 인쇄 기능 활용 |

#### 섹션 구성

| 섹션 | 내용 |
|------|------|
| 섹션 1 | 관찰자 기록 (위생·안전 체크리스트) |
| 섹션 2 | 피시술자 정보 및 생체징후 |
| 섹션 3 | 탐혈/시술 및 초음파영상 |
| 섹션 4 | 학습 성찰 |
| 섹션 5 | OSCE 채점 |

## 실습 진행 순서

```
① 체크리스트 — 피험자 동의서 및 사전 체크리스트 작성
        ↓
② 실습일지 — 탐혈·자침·초음파영상 기록
        ↓
① 체크리스트 — 사후 체크리스트 작성
        ↓
② 실습일지 — 파일 통합 (조원별 JSON 합산)
        ↓
PDF 출력
```
