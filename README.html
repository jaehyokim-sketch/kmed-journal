원광대학교 한의과대학 경혈학교실 & 침구의학교실

경혈학실습 & 경혈학임상술기실습 일지

탐혈 · 자침 · 초음파영상 통합 실습을 위한 조별 실습일지 (Group Practice Journal)

단일 HTML 파일로 구성된 조별 실습일지입니다. 별도 설치나 서버 없이 브라우저에서 바로 사용할 수 있으며, 탐혈 · 자침 · 초음파영상 기록을 통합하여 관리합니다.

주요 기능

실습 기록
관찰자 기록(위생·안전 체크리스트), 피시술자 정보(생체징후), 경혈별 탐혈/자침/초음파영상, 개인 성찰, OSCE 채점 결과를 체계적으로 기록합니다.
경혈 선택
14경맥 + 경외기혈 전체 드롭다운 제공. SCM0003-2009 기준 ★ 상용수혈 130穴 강조 표시. 전체 361穴 한도 내 자유 추가.
데이터 저장 · 불러오기
작성 내용을 JSON 파일로 로컬 저장하고, 저장 파일을 불러와 이어서 작성할 수 있습니다. PDF 저장(브라우저 인쇄)도 지원합니다.
파일 통합 (File Merge)
조원별 개별 저장 파일을 하나의 최종 일지로 자동 병합합니다. 섹션 3 경혈 기록과 섹션 4 성찰은 모든 파일에서 수집·합산합니다.
기능설명
데이터 저장작성 내용을 JSON 파일로 로컬 저장
불러오기저장된 JSON 파일을 불러와 이어서 작성
파일 통합조원별 개별 저장 파일을 하나의 최종 일지로 자동 병합
PDF 저장브라우저 인쇄 기능으로 PDF 출력
파일 통합 알고리즘
항목처리 방식
섹션 3 경혈 기록모든 파일에서 수집 후 합산
섹션 4 성찰모든 파일에서 비어 있지 않은 항목 수집
기본정보 · 체크리스트 · 섹션 5기준 파일(사용자 선택) 적용
이미지모든 파일에서 통합 (기준 파일 우선)

사용 방법

개별 실습 진행
1
기본정보 입력
날짜·분반·조·주제·지도교수를 입력하고 조원 이름과 역할을 확인합니다.
2
섹션 순서대로 작성
관찰자 체크리스트 → 피시술자 생체징후 → 경혈 기록 → 성찰 순으로 진행합니다.
3
수시 저장
[데이터 저장] 버튼을 눌러 JSON 파일로 주기적으로 저장합니다.
조별 최종 일지 완성
1
개인 파일 준비
조원 각자가 섹션 3(시술 경혈 기록)과 섹션 4(성찰)를 작성하고 저장합니다.
2
파일 통합 실행
조장이 [파일 통합] → 조원 JSON 전체 선택 → 기준 파일 지정 → [통합 실행]을 클릭합니다.
3
최종 출력
통합된 최종 일지를 저장하거나 PDF로 출력합니다.
