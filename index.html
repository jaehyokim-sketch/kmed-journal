체크리스트 열기

피험자(피시술자) 동의서 작성부터 시술 전·후 체크리스트까지 세 단계를 하나의 문서로 통합 관리합니다. 탭별 입력 시각을 자동 기록하여 최종 출력본(PDF)에 타임스탬프가 표시됩니다. 작성 내용은 JSON 파일로 저장·불러오기 가능합니다.

실습일지 열기

탐혈 · 자침 · 초음파영상 기록을 통합한 조별 실습일지입니다. 관찰자 위생·안전 체크리스트, 피시술자 생체징후, 경혈별 자침 기록, 개인 성찰, OSCE 채점 결과를 체계적으로 기록합니다. 조원별 개별 저장 파일을 하나의 최종 일지로 자동 병합하는 파일 통합 기능을 지원합니다.

실습 진행 순서: ① 체크리스트에서 피험자 동의서 및 사전 체크리스트를 먼저 작성 → ② 실습일지에서 탐혈·자침·초음파영상 기록 → ① 체크리스트에서 사후 체크리스트 작성 → 실습일지 파일 통합 → PDF 출력
