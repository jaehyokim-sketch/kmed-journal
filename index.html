경혈학실습 &
경혈학임상술기실습 일지

탐혈·자침·초음파영상 통합 실습을 위한 조별 실습일지입니다.
단일 HTML 파일로 구성되어 별도 설치 없이 브라우저에서 바로 사용할 수 있습니다.

실습일지 열기 → GitHub ↗

주요 기능

섹션별 실습 기록

섹션 1

관찰자 체크리스트

위생·안전관리 체크리스트 자동 채점. 항목별 점수 합산 및 평점이 실시간으로 계산됩니다.

섹션 2

피시술자 정보

생체징후(체온·혈압·혈당) 및 피시술자 기본정보를 구조화된 양식으로 기록합니다.

섹션 3

탐혈·시술 실습 기록

경맥 → 경혈 드롭다운 선택, 경혈별 아코디언 카드로 상세 기록. 경혈별 초음파영상 첨부 가능.

★ 상용수혈 130穴 (SCM0003-2009) 표시
섹션 4

개인 성찰

조원 각자의 성찰을 개별 입력. 파일 통합 시 전원의 성찰 내용이 자동으로 병합됩니다.

섹션 5

모의 OSCE 채점 이미지

관찰자가 작성한 모의 OSCE 채점표를 이미지(최대 4장)로 첨부합니다.

파일 통합

조별 일지 자동 병합

조원 각자가 저장한 JSON 파일을 하나의 최종 일지로 자동 통합. 경혈 기록·성찰·이미지가 모두 합산됩니다.

사용 방법

실습일지 작성 흐름

개별 실습 기록

  1. 실습일지를 열어 기본정보(날짜·분반·조·주제·지도교수)를 입력합니다.
  2. 조원 이름과 역할(시술자·피시술자·관찰자)을 확인합니다.
  3. 섹션 1→5를 순서대로 작성합니다.
  4. 작성 중 수시로 [데이터 저장]을 눌러 JSON 파일로 저장합니다.

조별 최종 일지 완성

  1. 조원 각자가 자신이 담당한 경혈 기록과 성찰을 작성 후 저장합니다.
  2. 조장이 [파일 통합]을 클릭합니다.
  3. 조원 전체의 JSON 파일을 선택하고 기준 파일을 지정합니다.
  4. [통합 실행]을 클릭하면 최종 일지가 완성됩니다.
  5. 최종 일지를 저장하거나 PDF로 출력합니다.
파일 통합 알고리즘
기본정보 · 체크리스트 (섹션 1·2) 기준 파일 적용
섹션 3 경혈 기록 모든 파일 수집 후 합산
섹션 4 성찰 모든 파일 비어 있지 않은 항목 수집
섹션 5 OSCE 이미지 모든 파일 통합 (기준 파일 우선)

기술 정보

브라우저만으로 동작

별도 설치나 서버 없이 브라우저만으로 동작합니다. 데이터는 사용자 기기에 JSON 파일로만 저장되며 외부 서버로 전송되지 않습니다.

Chrome (권장) Edge Safari Firefox 단일 HTML 파일 Vanilla JS 외부 의존성 없음
